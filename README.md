## 🧠 Sobre o projeto

O objetivo deste site é servir como uma vitrine profissional, reunindo informações sobre minha trajetória acadêmica, conhecimentos técnicos e projetos desenvolvidos.

Através dele, é possível conhecer melhor meu perfil como desenvolvedor, além de visualizar na prática algumas das soluções que desenvolvi.
